# 礼包预约与积分商城实施计划

**目标：** 建立独立的手机端、管理后台和服务端，支持业务规则记录中的礼包、积分、预约匹配、线下交易及商城。

**架构：** 参考 cym 的红白色移动端视觉与 Vue / Node 前后端分离结构。服务端以独立业务模块、数据库事务、审计流水与定时任务实现资产和订单状态；用户端四个主标签为首页、预约、商城、我的。

**实施顺序：**

1. 建立项目骨架，测试礼包复利、整数四舍五入、上限和随机匹配。
2. 建立独立数据库模型与事务，完成注册、认证、积分和礼包的管理及流水。
3. 完成预约冻结、按类型随机匹配、固定结果、线下交易、超时和人工干预，并验证并发与重复执行。
4. 完成商品、积分购买、地址、订单及提货码留言。
5. 制作用户端四个标签和管理后台，沿用参考项目视觉风格。
6. 联调定时任务、权限、安全和异常流程，准备部署说明；商业模式合规审查完成之前不对外上线。

具体规则以 `docs/业务规则记录.md` 为准；尚未确认的事项不擅自改变资产结果。实际实现逐项添加可执行测试并记录验证结果。
